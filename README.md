# selectr-skill

The `selectr-schema` agent skill: generates or updates a Selectr schema (a v2 base file plus its review report) for a PostgreSQL database.

Requires Node.js 24 on the machine running the agent.

## Install

As a Claude Code plugin (from a clone of this repo, or its git URL once published):

```
/plugin marketplace add <path-or-git-url>
/plugin install selectr-schema@selectr-skill
```

Or as a personal skill, available in every project:

```bash
ln -s "$(pwd)/skills/selectr-schema" ~/.claude/skills/selectr-schema
```
