# selectr-skill

The `selectr-schema` agent skill: generates or updates a Selectr schema (a v2 base file plus its review report) for a PostgreSQL database.

Requires Node.js 24 on the machine running the agent.

## Install

As a Claude Code plugin:

```
/plugin marketplace add dmantilla/selectr-skill
/plugin install selectr-schema@selectr-skill
```

To pick up a new version later:

```
/plugin marketplace update selectr-skill
```

Or as a personal skill, available in every project: clone the repo anywhere, then link the skill into `~/.claude/skills`:

```bash
git clone https://github.com/dmantilla/selectr-skill.git
ln -s "$(pwd)/selectr-skill/skills/selectr-schema" ~/.claude/skills/selectr-schema
```

To update, `git pull` in the clone.
